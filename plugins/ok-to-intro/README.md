# OK to Intro for Claude Code

Ask a network for 20 minutes with one specific person, and answer what waits on you, without leaving Claude Code.

```
claude plugin install ok-to-intro --marketplace alan-arguello/ok-to-intro
```

Older Claude Code: `claude plugin marketplace add alan-arguello/ok-to-intro`, then `claude plugin install ok-to-intro@ok-to-intro`. Inside a session, type `/plugin` instead of `claude plugin`.

## What it adds

- **MCP server `ok-to-intro`** (`.mcp.json`): 9 tools. `try_rules` and `draft_ask` are open; `send_ask` and `answer_question` also work without a token on the SAMPLE network (40 fictional members, nobody emailed); `my_asks`, `pending_for_me`, `respond`, `set_rules` and `record_outcome` need your token. `send_ask`, `answer_question` and `respond` ask you before every call, even in auto mode.
- **`/ask` skill** (`skills/ask/SKILL.md`): drafts an ask from your repo, citing file and line for every fact; sends only after your yes.
- **Session hook** (`hooks/`): at session start and resume, at most 3 lines when something waits on you; silent otherwise, and after 2 seconds.

## Your token

Optional. Create one under Your gate on the site; Claude Code asks for it at install and keeps it in your OS keychain (`claude plugin configure ok-to-intro` changes it). It is sent only as the `Authorization` header to the OK to Intro server, and to the session hook's request on stdin, never as a command-line argument.

The MCP URL in `.mcp.json` and the hook URL in `hooks/hooks.json` are generated by `scripts/build-plugin.ts` from the site's origin.
